# Mandatory and Preferred Criteria

Mandatory criteria are explicitly required for the vacancy. Common markers include required, must have, mandatory, essential, and minimum.

Preferred criteria are useful but non-essential. Common markers include preferred, nice to have, good to have, bonus, and advantage.

When a skill is not qualified by either type of marker, Agent 2 may treat it as mandatory conservatively. An unrelated required education or experience phrase must not reclassify a preferred skill.
