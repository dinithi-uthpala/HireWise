# Software Engineer Competency Framework

## Role scope

A software engineer designs, implements, tests, and maintains software systems.

## Typical capabilities

- Programming with languages such as Python, Java, JavaScript, C++, or C#
- Version control and collaborative development
- Testing, debugging, and code review
- API or application design appropriate to the role
- Clear technical communication

## Typical responsibilities

- Implement maintainable features against approved requirements.
- Review changes and document important design decisions.
- Test behavior and investigate defects.
- Consider security, reliability, and operational constraints.

## Typical experience and education

Requirements vary by level. Use the vacancy's explicit experience and qualification criteria rather than this general guidance.
