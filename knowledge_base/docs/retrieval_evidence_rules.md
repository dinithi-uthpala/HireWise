# Retrieval Evidence Rules

Retrieved documents provide approved role guidance and explanations for Agent 2. Retrieval must not replace deterministic score calculation.

Evidence should identify the source document and relevant content. Retrieval content must be general project knowledge and must not contain candidate names, contact details, raw CV text, or other personal data.

If no approved document is retrieved, Agent 2 should report that evidence is unavailable rather than inventing criteria.
