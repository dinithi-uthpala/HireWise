# Data Analyst Competency Framework

## Role scope

A data analyst turns operational data into clear, job-related insights for decision support.

## Typical mandatory capabilities

- SQL and relational database querying
- Python for data analysis
- Spreadsheet analysis with Excel
- Data cleaning and validation
- Basic statistics and analytical problem solving

## Typical preferred capabilities

- Pandas data manipulation
- Power BI, Tableau, or Looker Studio dashboards
- Data visualization and data storytelling
- ETL or data pipeline awareness

## Typical responsibilities

- Query and join structured datasets.
- Clean, validate, and document data preparation steps.
- Produce repeatable reports and explain findings to stakeholders.
- Build dashboards and visualizations when the role requires them.
- Record assumptions, limitations, and evidence for analytical conclusions.

## Typical experience and education

Junior roles commonly request 0-2 years of relevant work, project, internship, or placement experience.
A Bachelor-level qualification in analytics, computing, statistics, business, or a related field may be relevant.
Criteria must be checked against the vacancy rather than assumed from this framework.
