# Sample CVs

Demo CVs used for development, the fairness-test mode and the viva demo.
Generate them with `scripts/generate_sample_cvs.py` (PDF + DOCX).

Planned samples:
  - `cand_001_junior_data_analyst.pdf`  - strong match
  - `cand_002_junior_data_analyst.docx` - potential match
  - `cand_003_manual_review.pdf`        - low extraction confidence
  - fairness pair:
    - `fairness_pair_a_male.docx`
    - `fairness_pair_b_female.docx`     (same qualifications, different IDs)

Note: names/photos in sample CVs are fictional and must be treated
as PII during development/testing.
