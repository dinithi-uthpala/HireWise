# Recruitment Scoring Guidelines

Agent 2 provides decision support, not a final hiring decision. Numeric scores must be deterministic and auditable.

The active HireWise configuration weights are:

- Mandatory skills: 45 percent
- Relevant experience: 25 percent
- Education: 15 percent
- Preferred skills: 15 percent

Each component is calculated from explicit vacancy requirements and anonymous CandidateProfile fields. Missing evidence must be represented as a gap or warning; it must not be silently invented.
